# Changelog

All notable changes to Enhanced Widget Control are documented here.

## 2.16.1

- Fixed automated CurseForge and GitHub release credentials.
- Kept automated Wago publishing and Retail 12.0.7/12.1.0 compatibility.

## 2.16

- Added Retail Interface support for 12.0.7 and 12.1.0.
- Added CurseForge and Wago project metadata for automated releases.
- Added automated packaging and publishing through GitHub Actions.

## 2.15.0

- Added an original Enhanced Widget Control addon icon.
- Added public release documentation and promotional artwork.
- Prepared the addon for packaged distribution.

## 2.14.5

- Added the MIT License for the addon source and original EWC media.
- Documented the separate SIL Open Font License for the bundled Play font.

## 2.14.4

- Replaced the preview toggle with an Open Widget Gallery button.
- Added a close button to the draggable widget gallery.
- Corrected preview scaling so widget, bar and text scale independently.
- Ensured preview values render above status-bar textures.
- Added clearer counter, timer, progress and percentage examples.

## 2.14.0

- Added a compatibility loader for missing or outdated ElvUI versions.
- EWC now stops cleanly and displays a readable chat message instead of
  producing follow-up Lua errors.

## 2.13.0

- Added the bundled EWC Play Bold font.
- Added the original EWC Dark status-bar texture.
- Included the SIL Open Font License for Play Bold.
- Removed the media dependency on third-party ElvUI plugins.

## 2.12.0

- Split import/export into Global Settings, Presets, Widgets and Backups.
- Added dedicated validation and destination controls for each data type.
- Connected per-widget export directly to the Widgets transfer page.

## 2.11.0

- Reorganized General settings into Overview, Preview, Presets,
  Global Style, Value Text, Position and Maintenance.
- Moved Import / Export into its own main section.

## 2.10.0

- Added the read-only EWC Default built-in preset.

## 2.8.0

- Added versioned compressed import/export strings.
- Added automatic pre-import backups.
- Added widget categories, search, favorites and custom names.

## 2.7.0

- Added the widget gallery preview and personal preset management.

## 2.0.0

- Rebuilt Enhanced Widget Control as an ElvUI module.
- Added automatic Blizzard widget detection.
- Added global styling with optional per-widget overrides.
- Added independent widget, bar and text positioning.
